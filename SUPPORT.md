# Support

Thanks for using Openwater's open-source platforms. Here's the fastest way to get help.

## Questions and usage help
- **Search existing issues** in the relevant repository first.
- Open a new issue using the **Bug report** or **Feature request** template if you don't find an answer.
- General discussion: the repo's Discussions tab where enabled.

## Licensing questions
Not sure whether a file is AGPL or Apache, or how you may use it? Open a **License question** issue
(template provided) or consult
[`license-manifest`](https://github.com/OpenwaterHealth/license-manifest), the source of truth for
per-path license assignments.

## Certifying a deployment
To have a deployment listed as **Openwater-Certified**, open a **Certification application** issue.
See [`openwater-certification`](https://github.com/OpenwaterHealth/openwater-certification) for the
program and requirements.

## Security issues
**Do not** open a public issue for vulnerabilities. Follow [SECURITY.md](SECURITY.md).
